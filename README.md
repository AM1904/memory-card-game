Hello, this is a memory card game built with react. 

To try it out, you can follow the below steps: 

Install the dependencies:
npm install

Run the project:
npm start

This will start the Vite development server. Open your browser and navigate to localhost to play the game.

How to Play the Memory Game? 
Click on a card to flip it and reveal the emoji.
Click on another card to try and find the matching emoji.
If the emojis match, the cards will stay flipped. If not, they will flip back over.
Continue until all pairs are matched.

Technologies Used :
React, Vite, CSS
